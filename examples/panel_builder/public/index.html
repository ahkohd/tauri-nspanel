Panel Builder Example

This example demonstrates using the PanelBuilder API to create panels programmatically. The mini panel is created during app initialization using the builder pattern.

Panel Controls

Note: The panel is created with PanelBuilder during app startup. It demonstrates:
  • Creating panels without converting existing windows
  • Configuring panel properties using the builder pattern
  • Setting up event handlers for panel lifecycle
  • Using custom panel classes with PanelBuilder
