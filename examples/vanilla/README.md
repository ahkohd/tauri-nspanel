# Demo
This demo uses the [tauri-nspanel](https://github.com/ahkohd/tauri-nspanel) crate to convert a standard Tauri [Window](https://docs.rs/tauri/1.8.1/tauri/window/struct.Window.html) ([NSWindow](https://developer.apple.com/documentation/appkit/nswindow/)) to [NSPanel](https://developer.apple.com/documentation/appkit/nspanel/).

```bash
pnpm install

pnpm tauri dev
```
